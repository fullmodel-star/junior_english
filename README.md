# 國中英文題庫 · 內部版

> 🔐 **版權處理方式：題庫資料以密碼（PBKDF2 + AES-256-GCM）加密後才內嵌。**
> 只有輸入正確密碼，才會在瀏覽器裡把資料解密。即使 `index.html` 放上公開站
> （GitHub Pages），下載到的也是加密亂碼，沒有密碼看不到任何題目內容。
> 因此**只有加密後的 `index.html`／圖示可以公開**；
> `data_supplement/`（子代理抽出的**明文**題目）與建置暫存已用 `.gitignore` 擋住，永不上傳。
>
> 公開站：`https://fullmodel-star.github.io/junior_english/`
> 🔑 **密碼不寫在此檔**（寫進來就等於公開，破壞加密的意義）。密碼請私下保管。

## 這是什麼
把 `E:\英語資料庫\國中英文`（02_文法 + 03_閱讀）的翰林教材，做成一支
**自包含、密碼鎖、可離線**的題庫練習 App（單一 `index.html`）。

- 📗 **文法**：文法特快車、精熟句型—應用篇、精熟句型—生活篇 + 自編補充（非版權）
- 📘 **閱讀**：ASK素養、情境式、整合式 L1–L3、輕素養 1/3（附閱讀文本）
- 依 **書系 → 主題單元** 導覽，每單元可先看 📖觀念講義 再練習
- 📝 **錯題本**：答錯自動收錄，答對 2 次才畢業；依書系分組複習
- ⚙️ 進度存本機瀏覽器；可改密碼、清除進度

**題數**：文法 671、閱讀 562（配 184 篇文本）、文法講義 20 篇。

## 密碼
預設通行密碼 **`csd2026`**，可在 App 內「設定 → 修改通行密碼」更改。
勾「記住登入」後同一裝置不再詢問。密碼以 SHA-256 存本機，非明文。
（說明：純前端鎖僅用於「版權合規、擋一般人直接使用」，非軍規加密。）

## 怎麼用
- **電腦**：直接雙擊 `index.html` 即可離線使用。
- **手機（同一 Wi-Fi）**：雙擊 `啟動手機版.bat`，手機瀏覽器輸入顯示的 `IPv4:8080`；
  Android Chrome／iOS Safari 可「加入主畫面」當 App 用。
